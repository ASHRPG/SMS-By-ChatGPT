# Student Management System (ASP.NET VB.NET)

Classic ASP.NET Web Forms Student Management System using VB.NET and SQL Server 2014.

## Features
- Student CRUD
- Department lookup
- Course lookup
- GridView binding
- ADO.NET
- Stored Procedures
- Login System

## Technology
- ASP.NET Web Forms
- VB.NET
- SQL Server 2014
- ADO.NET

## Database
Run `Database/StudentManagementSystem.sql` in SQL Server Management Studio 2014.
